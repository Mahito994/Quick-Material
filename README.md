# Quick-Material by Mahito
[![Download](https://img.shields.io/badge/Download-Latest%20Release-blue?style=for-the-badge)](https://github.com/Mahito994/Quick-Material/releases)

Quick-Material is a modern utility tool for Windows designed to quickly perform common system tasks with a clean Material Design 3 interface. For example, opening terminals (normal or admin), managing apps, or clearing temporary files, the recycle bin, and browser caches from Firefox, Chrome, Edge, etc. with just one click plus handy built-in extras like a quick IP address lookup and a speed test. If anyone has requests or ideas that I can add, DM me and I wouldnt mind to review and add them to the utility. Thanks for everyone trying out this utility tool, thanks and have fun :)

## Features

- Quick open Terminal with and without admin
- Quick open the Registry Editor
- Quick open the old Control Panel delete application panel
- Quick open the device manager
- Quick open the task manager
- Clearing the temporary files in C:/Windows/Temp
- Clearing the Recycle Bin
- Quickly making a Disk Cleanup
- Clearing the Browser Cache (Firefox, Chrome, Edge, etc...)
- Showing the Local & Public IP-Address
- Making an Internet Speed Test (via integrated speedtest.exe)

## Installation

You can install **Quick-Material** in two different ways depending on whether you want the ready-to-use executable or run the project from source.

### Method 1 — Download the Executable (Recommended)

1. Go to the [Releases](https://github.com/Mahito994/Quick-Material/releases) page of this repository
2. Download the latest setup `.exe` file
3. Run the installer/executable

No Node.js installation is required for the pre-built release.

---

### Method 2 — Run from Source

> [!IMPORTANT]
> Make sure that you have [Node.js](https://nodejs.org/) installed first. (you can check with `node -v`)

1. Clone the repository

```bash
git clone [https://github.com/Mahito994/Quick-Material.git](https://github.com/Mahito994/Quick-Material.git)

```

2. Navigate into the project folder

```bash
cd Quick-Material

```

3. Install the required dependencies

```bash
npm install

```

4. Run the application

```bash
npm start

```

## Tech Stack & Dependencies

Quick-Material is built using modern web technologies and Electron, styled with Beer CSS and Material Design 3 components.

| Package / Tool | Purpose |
| --- | --- |
| **Electron** | Framework for building cross-platform desktop applications using JavaScript, HTML, and CSS. |
| **Beer CSS** | Lightweight CSS framework implementing Material Design 3 design guidelines and dynamic shapes. |
| **material-dynamic-colors** | Generates dynamic Material You color schemes based on themes. |
| **speedtest.exe** | Integrated Ookla CLI tool for fast and accurate internet speed testing. |
| **electron-builder** | Used to package and build the application into a standalone Windows installer and executable. |
